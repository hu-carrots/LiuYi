================================================================
                       六一桌宠（LiuYi）使用说明
================================================================

一、这是什么
----------------------------------------------------------------
一只住在桌面上的 Q 版布偶猫。它会在屏幕底部散步、累了打盹，
被摸会眯眼蹭头，被连戳会炸毛；还会提醒你喝水、记着你的纪念日。
当前版本 v2.2（第一期：桌宠功能对齐，离线，不含 AI）。


二、怎么启动
----------------------------------------------------------------
推荐：从 GitHub Releases 下载 LiuYi.exe（单文件，不需要安装 Python）
源码：python "desktop_pet_v2.1.py"（先装依赖：pip install -r requirements.txt）
首次运行：把 pet.example.json 复制为 pet.json（不复制也能启动，程序会按默认值自动生成 pet.json）

启动后：
  * 桌面右下角出现一只小猫；
  * 任务栏右下角出现托盘图标（小猫头像）。

同一时间只会运行一只：重复双击不会开出第二只，只会把原来的叫出来。


三、能和它做什么
----------------------------------------------------------------
单击                被摸：眯眼、脸红，说一句撒娇的话
0.5 秒内再点一下     炸毛：跳一下 + 身体抖一抖，配生气台词
按住拖动            整只猫被"拎起来"（四肢下垂），松手放下；位置会记住
快速甩开松手        把猫抛出去：沿抛物线飞，落回起抛点同一高度，
                    全程不出屏幕；落地晕乎约 1.2 秒后回待机
滚轮                放大 / 缩小（0.5× ~ 2.5×）
右键                打开菜单

右键菜单：
  [✓] 始终置顶         勾上后一直压在其他窗口上面
  [✓] 动画开关         关掉后不眨眼、不甩尾、不散步（省电）
  [ ] 省电模式         和关动画类似，但保留基本显示
      模式             自由散步 / 跟随鼠标 / 原地待着（三选一）
      语录频率         安静 / 正常 / 话多 / 话痨（闲聊间隔不同）
      大小             迷你 / 特小 / 小 / 中 / 大（另有滚轮无级调）
      窗口层级         置顶 / 普通 / 置底
  [ ] 锁定位置         勾上后拖不动，点它、右键照旧
  [ ] 鼠标穿透         勾上后点不中猫，从托盘右键解除
  [ ] 开机自启         下次开机自动出现（仅 Windows）
      查看天气         报默认城市的实况（免 Key，联网查）
      今日汇总         报今天的互动/散步/提醒次数（没有余额）
      免打扰           15/30/60/120 分钟，期间不说话，结束汇总攒下的提醒
      喂个小零食       它会张嘴嚼两下（约 1 秒）并说一句话
      伸个懒腰         蹲下再前爪前伸，约 1.8 秒后回待机
      打个哈欠         小口微张再大口捂嘴，约 1.8 秒后回待机
      扒拉一下文件     先试真实模式：走过去用推帧推一个真的桌面图标
                       （约 32px，说出文件名），不行才原地扒拉
                       道具纸，约 1.8 秒后回待机
      推一下桌面图标   手动推一个真实的桌面图标（仅 Windows；
                       不是自由散步模式或没图标时，原地扒拉一次）
      把图标放回去     把推过的图标全部恢复到原始位置（没推过
                       时点不了；恢复完备份清空）
      设置…            打开设置窗口（6 个页签）
      把六一放回右下角  位置跑飞了用这个
      退出

托盘图标（任务栏右下角）：
  左键单击            显示 / 隐藏
  右键                一样的菜单，另外多了"喂个小零食"等常用项


四、它会自己做什么
----------------------------------------------------------------
* 待机闲聊    正常档每隔 18~35 秒随缘说一句，不重复；
              设置里可改安静/话多/话痨，也能按类别关掉某类话
* 跟随鼠标    模式改成“跟随鼠标”后，它会慢慢跟到光标下面
* 定时提醒    设置里可加：每天指定时间 / 每周选几天 / 每隔 N 分钟；
              默认每天 23:30 说一句“该睡了”
* 天气        右键 → 查看天气，报默认城市的实况
* 应用提醒    受关注的应用（默认 Steam/WeGame/VS Code）连续用满
              设定分钟就提醒一次；挂机不计时；换应用重新计时
* 散步        不定时在屏幕底部横向走动，碰到屏幕边缘自动转身；
              起步和收步有缓动，走的时候身体会随步子轻微起伏
* 打盹        连续 5 分钟没人理它 → 先打一个哈欠（约 1.2 秒，
              图缺了直接睡），再趴下睡觉（头顶飘 Zzz）
              连续 10 分钟 → 进入深睡
* 伸懒腰      待机 90 秒以上会随机伸个懒腰；深睡醒来也有约
              三分之一概率先伸懒腰；右键菜单可手动点
* 打哈欠      待机 90 秒以上会随机打哈欠；睡前会先打一个；
              右键菜单可手动点。三个新动作约 1.8 秒，做完
              回待机；吃东西、走路、睡觉时不触发
* 扒拉文件    待机 90 秒以上会随机扒拉一下桌面上的文件；
              右键菜单可手动点。先试真实模式：走过去用推帧推一个
              真的桌面图标（约 32px，说出文件名），不行才
              原地扒拉道具纸。推之前记下图标原始位置，
              右键“把图标放回去”可以一键恢复；每次只推
              一个图标，图标不会出屏幕
* 抛掷        拖着猫快速一甩再松手，猫沿抛物线飞出去，落回
              起抛点同一高度，全程不出屏幕；落地先低身下
              蹲约 0.25 秒，再晕乎约 1.2 秒说一句台词后回
              待机；慢慢松手不抛，飞行中抓住就取消
* 唤醒        鼠标移到猫身上，或点它一下，立刻醒
* 喝水提醒    默认每 45 分钟提醒一次；深睡期间攒着，醒来补一句
* 纪念日      设置里填了名字和日期后：启动时打招呼、每天提醒一次，
              快到时还会在跳跃时偷偷预告


五、设置项（右键 → 设置…，共 6 个页签）
----------------------------------------------------------------
提醒与纪念日：
  喝水提醒      开关 + 间隔（分钟，默认 45）
  多久打盹      无操作多少分钟进入浅睡（默认 5）
  多久深睡      全局空闲多少分钟进入深睡（默认 10）
  纪念日名称    例如"认识纪念日"，留空则不提醒
  纪念日日期    选日期
  高 DPI        高分辨率屏幕上更清晰；改完要重启程序才生效
语录：
  闲聊频率      安静 / 正常 / 话多 / 话痨
  类别开关      日常闲聊 / 被摸回嘴 / 拖拽 / 离开返回 / 喝水提醒 /
                喂食 / 睡眠 / 纪念日 / 快捷键，各自开关
定时提醒：
  每天指定时间 / 每周选几天 / 每隔 N 分钟，可增删改
模式与窗口：
  模式（自由散步/跟随鼠标/原地待着）、窗口层级、透明度、
  大小档位、锁定位置、鼠标穿透、开机自启
应用与快捷键：
  应用使用时长提醒（应用名 + 分钟，可增删）、应用启动说一句、
  全局快捷键（默认 Ctrl+Alt+1 夸一句、Ctrl+Alt+2 安慰一句、
  Ctrl+Alt+3 损一句，可新增/删除；仅 Windows 生效）
天气：
  默认城市（默认上海）、立即查看天气

设置会立即保存，关掉窗口再开也还在。


六、文件说明
----------------------------------------------------------------
LiuYi.exe            打包好的主程序（不在仓库里，从 Releases 下载）
pet.example.json     配置模板（默认值，不含个人数据）
pet.json             你的所有设置（本地生成，不入库；首次运行可从模板复制）
image\               素材图片（处理好的 600×600 透明 PNG，运行时用这套）
source\              素材原图（2048px JPG，供 import_frames.py 处理）
desktop_pet_v2.1.py  源码启动器（开发者用，文件名是历史名称）
ragdollpet\          源码模块（开发者用）

注意：pet.json 在程序所在目录（exe 旁边）。换电脑或重装时，
把 pet.json 一起拷过去，位置和纪念日都还在；不要把个人
pet.json 提交进仓库。


七、换素材（不用重新打包）
----------------------------------------------------------------
素材分两套：source\ 是 2048px JPG 原图，image\ 是处理后的
600×600 透明 PNG，运行时用 image\。
1) 在程序同目录建一个 image 文件夹（源码运行则用仓库里的 image\）；
2) 把图片按下面的名字放进去，重启程序即可。

  cat_idle.png    睁眼坐着（必需）
  cat_blink.png   闭眼（眨眼用，可选）
  cat_sleep.png   趴睡（可选）
  cat_pet.png     眯眼被摸（可选）
  cat_click.png   炸毛（可选）
  cat_hold.png    被拎起（拖动时用，可选）
  cat_eat.png / cat_eat2.png   吃东西两帧（张嘴 / 闭嘴，可选）
  cat_stretch_1.png / cat_stretch_2.png   伸懒腰两帧（蹲着准备 / 前爪前伸，可选）
  cat_yawn_1.png / cat_yawn_2.png   打哈欠两帧（小口微张 / 大口捂嘴，可选）
  cat_idle_breath_1.png / cat_idle_breath_2.png   待机呼吸两帧（吸气 / 呼气，可选）
  cat_sleep_breath_1.png / cat_sleep_breath_2.png   睡觉呼吸两帧（吸气 / 呼气，可选）
  cat_throw_1.png / cat_throw_2.png   抛掷两帧（甩出 / 翻滚，可选）
  cat_land_1.png   落地一帧（低身下蹲，可选）
  cat_dizzy_1.png   晕乎一帧（蚊香眼 + 星星，可选）
  cat_walk_1.png … cat_walk_8.png   走路的循环帧（1–8 张，可选）
  tray_icon.png   托盘图标（可选）

缺哪张都不会崩，会退回上一级表现（例如没有 cat_blink 就整体压扁当眨眼）。

图片要求：
  * 透明背景的 PNG（白底图会显示成一个白方块）；
  * 建议 600×600 或更大；
  * 脚底大致对齐同一条水平线，否则换帧时会"上下跳"。
  如果尺寸不标准但带透明通道，程序会自动缩放对齐；白底 JPEG 会提示你处理。


开发者补帧导入（需下载源码，exe 不包含此工具）：
  在仓库根目录安装 Python 3.9+ 和 Pillow：
    python -m pip install -r requirements-import.txt
  用仓库 source/ 的 4 张走路原图试跑：
    python import_frames.py --out walk_test --fit per-frame
  检查 walk_test/walk_preview.png；确认后导入 image/，重启桌宠：
    python import_frames.py --fit per-frame --overwrite
  自定义素材：
    python import_frames.py "新帧文件夹" --out walk_test --fit per-frame
  已透明的图可加 --no-cut。文件夹只扫描当前层，按自然编号排序；
  支持 PNG/JPG/JPEG/WebP/BMP，共 1–8 张，每张一个姿态，不切拼图。
  默认 --fit uniform 保留相对大小；per-frame 分别适配内容高度。
  --out 默认脚本旁 image/；已有帧会拒绝覆盖，需另选目录或加 --overwrite。
  --overwrite 会清理超出本次帧数的旧编号帧，禁止覆盖输入原图。
  输出为 600×600 透明 PNG，最大内容高 482，内容下边界 549，水平居中。
  白底 / 下半部浅灰阴影仅按边界连通阈值去除，不保证所有阴影都能去掉；
  可调 --white-threshold（默认240）、--shadow-threshold（默认210，0禁用）。
  复杂背景、粘连阴影需手工处理后用 --no-cut；请始终检查预览。
  工具不依赖 PyQt5；运行桌宠仍需 PyQt5。更多参数见 python import_frames.py --help。


八、常见问题
----------------------------------------------------------------
Q: 桌面上是个白方块，看不到猫？
A: 那张图是白底 JPEG。用透明背景的 PNG 替换，或按第七节放好素材。

Q: 猫跑出屏幕了 / 找不到了？
A: 托盘右键 →「把六一放回右下角」。

Q: 双击了没炸毛？
A: 两次点击要在 0.5 秒内；慢了就变成了"被摸"。也可以连点三下。

Q: 改了高 DPI 没反应？
A: 这个开关只能在程序启动时生效，改完重启。

Q: 放大到 2 倍有点糊？
A: 素材决定清晰度。换成 1024 或 2048 的原图会明显变好。

Q: 设置丢了 / 每次启动都像第一次？
A: 检查 pet.json 是不是和 exe 在同一个目录、有没有写权限。

Q: 托盘没有图标？
A: 缺 tray_icon.png 时会用猫的待机图代替；如果连图都没有，程序照常运行，只是没有托盘。

Q: 打开时杀毒软件报警？
A: PyInstaller 打包的单文件程序常被误报，添加信任即可。


九、恢复默认 / 卸载
----------------------------------------------------------------
恢复默认设置：关闭程序，删掉 pet.json，再启动。
彻底卸载：删掉整个文件夹。程序不写注册表、不在系统目录留东西
（第一次启动会把旧版注册表里的设置迁移到 pet.json，之后不再读注册表）。


十、已知限制
----------------------------------------------------------------
* 只支持 Windows 10 / 11；
* 没有声音；开机自启已支持（设置 → 模式与窗口 / 右键菜单）。
* 多显示器切换、150% 缩放下的观感没有逐个验证过；
* 眨眼使用独立的闭眼帧；如果素材里没有，会退化成"整体压扁"，观感一般；
* 拖到屏幕边缘会被钳住，不会跑到屏幕外。
* 抛出去也不会飞出屏幕，落点和顶点都算好留在屏内。
* 推图标（仅 Windows）会真的移动桌面图标：每次只推一个、
  只挪约 32px，图标不会出屏幕；原始位置存在程序目录的
  icon_layout_backup.json 里，右键“把图标放回去”可以一键
  恢复；开了“自动排列图标”时推不动，属正常。
